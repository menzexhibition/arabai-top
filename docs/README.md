# ARABAI Internal Docs

This directory stores internal planning, operation, and handoff documents that should not clutter the public static website root.

## Directory Map

- `handoff/` — engineering handoff notes and project context for future maintainers.
- `operations/` — deployment, DNS, analytics, backup, and maintenance checklists.
- `product/` — real-case tutorial planning, content gaps, and product execution notes.
- `research/` — research process and safety notes.
- `legal-compliance/` — Lemon Squeezy, payment review, and compliance preparation files.

## Placement Rule

Keep public static pages such as `index.html`, `ar-*.html`, legal pages, assets, and app files in the site root or their existing feature directories. Put internal guidance files here unless they are directly tied to a deployable service such as `deploy/new-api/`.
