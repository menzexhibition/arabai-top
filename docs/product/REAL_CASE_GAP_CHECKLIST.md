# ARABAI Real Case Gap Checklist

This checklist tracks the remaining real-case tutorials that still need full beginner-usable proof.

Rule:
- A “real case” is not only a screenshot.
- It should include: real task, real input, real tool flow, real output, and a result a normal user can copy.
- Best format: video + article + screenshots + final downloadable result when possible.

## Priority Levels

- P0: Needed to complete the beginner-to-action story loop
- P1: Strongly improves trust and practical value
- P2: Good expansion after the core loop is complete

## Recording standard

For every future real case, collect all of these:

- Screen recording
- 4-8 key screenshots
- Final prompt text
- Final output text / file / media
- Short Arabic summary
- “What to check before you trust this result”
