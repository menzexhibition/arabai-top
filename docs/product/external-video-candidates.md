## Selection Rules

- Arabic first; English only when the visual workflow is very clear.
- Beginner-friendly.
- Shows actual operation, not only abstract explanation.
- No piracy, cracked tools, or unsafe workflow.
- No aggressive course selling.
- Prefer official tutorials or trusted creators.
- Prefer recent videos, ideally within the last 6-12 months.
- Confirm whether embedding is allowed before adding to the public site.
