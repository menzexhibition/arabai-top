# ARABAI Real Case Tutorial Requirements

## Background

ARABAI is an Arabic-first AI guide website for ordinary users in Saudi Arabia and the Middle East. The site is not meant to be a technical AI encyclopedia. Its main goal is to help beginners understand what AI large-model tools can do and then follow simple steps to complete real work.

The current website has many articles with explanations, prompts, links, and some sample outputs. However, the owner believes the current tutorial content is still not enough for a complete beginner because many articles do not show the full real operation process, real tool interface, prompt refinement, and final usable result.

## Core Problem

The articles must stop feeling like "talking about AI" and become practical, step-by-step real case tutorials.

A normal user who only knows how to type should be able to open one article, follow it from top to bottom, and complete the task without needing outside knowledge.

## Target Audience

- Arabic-speaking beginners, especially users in Saudi Arabia and the Middle East.
- Users who may have heard of AI but do not know how to operate AI tools.
- Users who may later become interested in ARABAI Credits or official AI subscriptions after seeing real value.

## Tone Requirement

- Simple, direct, beginner-friendly.
- Use analogy and story-like explanation when introducing concepts.
- Avoid programmer language.
- Avoid long theory.
- Do not sound like machine translation.
- Arabic should feel natural for Arabic-speaking users.

## Tutorial Completion Standard

Each priority tutorial must include:

1. A real beginner task.
2. The exact AI tool used.
3. The official website or login page.
4. The exact prompt the user should copy.
5. Screenshot or video of the prompt being entered.
6. The first AI result.
7. At least one refinement prompt or adjustment step.
8. The improved final result.
9. A checklist that tells the user whether the result is usable.
10. For image, video, PPT, and music tasks, a real final asset, not only text.
11. Safe screenshots or videos that show only the relevant browser/tool interface.

## Privacy And Safety Rules For Screenshots / Videos

Published assets must not show:

- Codex or private chat with the owner.
- Desktop wallpaper or system UI unless absolutely necessary.
- Personal email, account name, billing details, phone number, API key, token, or payment method.
- Private files, folders, browser bookmarks, or unrelated tabs.
- Any account dashboard with sensitive usage or payment information.

Use clean demo accounts or carefully cropped browser-only captures whenever possible.

Before publishing any screenshot or video:

- Crop to the browser content area.
- Blur account names, emails, usage balances, API keys, and private details.
- Check every frame for accidental private content.
- Store raw captures in a private review folder first.
- Publish only safe exported assets.

## Priority Tutorials To Fix First

1. Writing with AI
   - Example task: rewrite a customer delay message.
   - Tool: ChatGPT, Claude, Gemini, Doubao, or another simple chat tool.
   - Must show original message, first result, refinement, final WhatsApp-ready message.

2. Planning with AI
   - Example task: create a 7-day launch plan for a small cafe or shop.
   - Must show prompt, first plan, request for checklist/table, final plan.

3. PPT / Presentation
   - Tool: Gamma.
   - Example task: create a 6-slide business presentation in English.
   - Must show Gamma prompt flow, outline review, generated deck, edits, export/share result.

4. Image Generation
   - Tool: image-2 or another selected image tool.
   - Example task: create a square Instagram poster.
   - Must show prompt, first image, refinement prompt, final downloadable image.

5. Video Generation
   - Main method requested by owner: text to image, then 9-grid storyboard, then stitch into video.
   - Tools can include image-2 plus CapCut/Canva/other video editor.
   - Must show 9 images, arrangement order, video editor timeline or process, final MP4.

6. Music Generation
   - Example task: create 20-second background music for a product video.
   - Must show prompt, first audio result, refinement, final playable audio.

7. Translation
   - Example task: translate a customer delivery message into natural Arabic for Saudi users.
   - Must include back-translation so non-Arabic owner can check meaning.

8. Document Summary
   - Example task: summarize a supplier proposal.
   - Must show source text, AI summary, action items, risk list.

9. API / Official API Purchase Flow
   - Must be safe and avoid real secrets.
   - Show concept of official API platform, billing limit, API key creation area with secrets hidden, and where the key would be stored.

10. ARABAI Credits / Gateway Flow
   - Current status is "coming soon".
   - Must show simulated user flow: recharge idea, choose tool, credits consumed, result returned.
   - Must clearly mark as planned/simulated until real backend and payment are live.

## Expected Final Deliverable

The final website should let a beginner:

1. Read a short explanation.
2. Open the exact tool.
3. Copy the prompt.
4. See what the screen should look like.
5. See what the first result looks like.
6. Learn how to refine the result.
7. Download, copy, export, or use the final result.
8. Understand when free use is enough and when paid use saves time.

## Definition Of Done

This issue is complete only when:

- All priority tutorials have real operation evidence.
- All priority tutorials have final usable outputs.
- All screenshots/videos are privacy-safe.
- Arabic users can follow the tutorial without technical background.
- The owner can audit the public pages and no longer see placeholder screenshots or text-only claims for image, video, PPT, and music tutorials.
