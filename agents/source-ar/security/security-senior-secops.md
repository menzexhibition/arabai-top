# تكوين وكيل: Senior SecOps Engineer

## القسم
أمن

## الوصف
هذا ملف تعريفي عربي لهذا الوكيل. ملف التكوين الكامل متوفر بالإنجليزية بعد تنظيفه من أي نص صيني مباشر.

## ملف التكوين الإنجليزي
[`security-senior-secops.md`](../source-en/security/security-senior-secops.md)

## طريقة الاستخدام
- استخدم هذا الوكيل كمرجع لدور متخصص داخل نظام وكلاء الذكاء الاصطناعي.
- راجع التعليمات الإنجليزية الكاملة قبل استخدامها في بيئة إنتاجية.
- عدّل الصلاحيات والأدوات والسياق حسب مشروعك.

## ملاحظة
لا يحتوي هذا الملف على تعليمات صينية مباشرة. إذا احتجت نسخة عربية كاملة لكل التعليمات، يجب ترجمة كل وكيل ومراجعته يدويا حسب الأولوية.
