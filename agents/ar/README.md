# مكتبة تكوينات وكلاء الذكاء الاصطناعي

هذا القسم يضع ملفات تكوين الوكلاء على موقع ARABAI بصيغة مناسبة للنشر، بدون عرض محتوى صيني مباشر.

- المشروع المصدر: `msitarzewski/agency-agents`
- الترخيص: MIT، راجع `../source-en/LICENSE`
- عدد ملفات الوكلاء المفهرسة: 232
- الملفات الإنجليزية: تكوينات Markdown منظفة داخل `../source-en/`
- الملفات العربية: أدلة عربية محلية داخل `../source-ar/`

## ملاحظة مهمة

الملفات الإنجليزية هي التكوينات الكاملة بعد تنظيف أي نص صيني مباشر. الملفات العربية تقدم فهرسة وشرحا عربيا لكل وكيل، ويمكن لاحقا ترجمة وكلاء مختارين بالكامل حسب الأولوية.
