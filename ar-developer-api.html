واجهة ARABAI للمطورين و API Token

هذه الصفحة تشرح للمستخدم العادي قبل المطور: ما الفرق بين أن تفتح نموذج ذكاء اصطناعي من موقعه مباشرة، وبين أن يستخدم موقع مثل ARABAI واجهة API لإرسال الطلب في الخلفية. بعد الفهم، نوضح بوابة api.arabai.top التجريبية لإدارة مفاتيح API وتتبع الاستخدام وربط نماذج متعددة من مكان واحد.

فتح بوابة API التجريبية فهم الرصيد أولا
شرح تدريجي للمستخدم العادي

فتح النموذج من موقعه شيء، واستخدامه عبر API شيء آخر.

تخيل أن موقع النموذج مثل مطعم تدخل إليه بنفسك: تفتح ChatGPT أو Gemini، تسجل الدخول، وتكتب طلبك داخل موقعهم. أما API فهو مثل نافذة خدمة خلفية: موقع ARABAI يستقبل طلبك بلغتك، يرسله إلى النموذج المناسب في الخلفية، ثم يعيد لك النتيجة داخل نفس التجربة.

1

الطريقة المباشرة

تفتح موقع النموذج بنفسك، تدير الحساب والدفع والإعدادات، وتتعلم واجهة كل أداة على حدة.

2

طريقة API

الموقع يرسل الطلب للنموذج في الخلفية. المستخدم يرى زر مهمة واضحا، وليس مفاتيح تقنية أو إعدادات معقدة.

3

لماذا بوابة واحدة؟

البوابة تساعد على تجربة أكثر من نموذج، مراقبة التكلفة، وتقديم رصيد مفهوم بدلا من حسابات كثيرة ومفاتيح متعددة.

الحالة الحالية

اختبار تقني قبل الإطلاق العام

بوابة API Token ليست خدمة بيع عامة الآن. الهدف الأول هو تشغيل النظام، حماية المفاتيح، ضبط القنوات، ثم اختبار الاستهلاك والتكلفة مع عدد محدود من الحسابات قبل فتح التسجيل أو الدفع للمستخدمين.

ماذا ستقدم البوابة؟

بدل بناء منصة فوترة ومفاتيح من الصفر، نستخدم بوابة جاهزة لإدارة الوصول إلى النماذج، ثم نربطها لاحقا بتجربة ARABAI العربية.

فصل واضح عن الموقع التعليمي

مقالات ودروس ARABAI تبقى مجانية. صفحة المطورين لا تعني أن الدفع أو شراء الرصيد مفتوح الآن، ولا تعني أن كل المستخدمين يستطيعون إنشاء مفاتيح API فورا. أي إطلاق عام يحتاج تسجيل دخول، شروط استخدام، خصوصية، دعم، وحدود استخدام واضحة.
